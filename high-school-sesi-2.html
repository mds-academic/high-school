Memahami IPO

IPO adalah singkatan dari Input, Process, Output. Ini adalah pola dasar banyak produk digital. Program menerima data, mengolahnya, lalu menampilkan hasil.

Dalam project Profil Nasabah

  • Input: pengguna mengetik nama, usia, rencana, dan target nominal.
  • Process: Python menyimpan data ke variabel dan melakukan casting untuk data angka.
  • Output: terminal menampilkan ringkasan profil nasabah.

Pola ini membantu kamu menulis program secara terstruktur. Kalau output salah, kamu bisa mengecek apakah masalahnya ada di input, proses, atau output.

Cara Kerja input()

input() digunakan untuk menerima ketikan pengguna dari terminal. Teks di dalam tanda kurung akan menjadi pertanyaan atau prompt yang muncul sebelum pengguna mengetik jawaban.

Contohnya, input("Masukkan nama nasabah: ") akan menampilkan prompt tersebut, lalu menunggu pengguna mengetik nama. Jawaban pengguna kemudian bisa disimpan ke variabel.

Membaca baris kode

nama = input(...) artinya: ambil data dari pengguna, lalu simpan hasilnya ke variabel nama.

Di slide ini, bagian Input simulator menggantikan ketikan pengguna di terminal. Saat praktik asli di Google Colab, kamu akan mengetik langsung ketika program meminta input.

Konsekuensi input()

Python menangkap hasil input() sebagai string. Ini berlaku untuk semua ketikan, termasuk angka. Jadi ketika pengguna mengetik 16, Python menyimpannya sebagai teks "16", bukan angka 16.

Kenapa ini penting?

Data bertipe string tidak bisa langsung dipakai untuk operasi matematika. Jika ingin menghitung usia, target nominal, atau estimasi tabungan, data angka dari input perlu dikonversi dulu.

Fungsi type() membantu mengecek tipe data yang sedang aktif. Ini sering dipakai saat debugging untuk memastikan data sudah berbentuk sesuai kebutuhan.

Naming Convention

Nama variabel yang baik membantu program mudah dibaca. Di Python, gaya yang umum dipakai adalah snake_case, yaitu huruf kecil dengan garis bawah sebagai pemisah kata.

Contoh yang baik

nama_lengkap, rencana_keuangan, target_nominal, dan durasi_bulan.

Hindari nama yang terlalu pendek atau tidak jelas seperti x, y, atau a untuk data penting. Nama seperti itu mungkin berjalan, tetapi menyulitkan saat program makin panjang.

Python case-sensitive

Nama dan nama dianggap dua variabel berbeda. Salah kapital bisa menyebabkan NameError.

str, int, dan float

Dalam project finansial sederhana, tiga tipe data ini paling sering muncul. str dipakai untuk teks, int untuk angka bulat, dan float untuk angka desimal.

Contoh penggunaan

  • nama_lengkap cocok menjadi str.
  • usia cocok menjadi int.
  • persentase_bunga atau nilai desimal cocok menjadi float.

Tipe data menentukan operasi yang boleh dilakukan. Teks tidak bisa langsung dibagi, sedangkan angka bisa. Karena itu, data dari input perlu diubah jika akan dipakai untuk perhitungan.

Kenapa Perlu Casting?

Karena hasil input() selalu string, data angka perlu dikonversi. Untuk angka bulat, gunakan int(). Untuk angka desimal, gunakan float().

Contoh

usia = int(input("Masukkan usia: ")) berarti: ambil input dari pengguna, lalu ubah hasilnya menjadi integer sebelum disimpan ke variabel usia.

Jika pengguna mengetik angka yang benar, program berjalan. Jika pengguna mengetik huruf untuk data yang diminta sebagai angka, Python akan memunculkan error. Ini akan kita bahas di bagian debugging.

Membaca ValueError

ValueError muncul ketika Python menerima nilai yang bentuknya tidak sesuai untuk operasi yang diminta. Dalam contoh ini, int() membutuhkan angka, tetapi input berisi teks huruf.

Contoh penyebab

Program meminta usia, lalu pengguna mengetik enam belas. Karena itu bukan karakter angka murni, int() tidak bisa mengubahnya menjadi integer.

Untuk sesi ini, cara mengatasinya adalah memasukkan angka dalam format yang tepat. Di level lanjutan, kamu bisa menambahkan validasi input agar program tidak langsung berhenti saat pengguna salah mengetik.

Latihan Klasifikasi Data

Nilai yang diberi tanda kutip adalah string, meskipun di dalamnya ada angka atau spasi. Contohnya, "Menabung untuk kuliah" adalah string karena merupakan teks.

Nilai 4.5 cocok menjadi float karena memiliki bagian desimal. Float sering dipakai untuk nilai seperti persentase, rasio, bunga, atau hasil pembagian.

Patokan cepat

  • Ada tanda kutip → biasanya str.
  • Angka bulat tanpa desimal → biasanya int.
  • Angka dengan titik desimal → biasanya float.

Kenapa Header Penting?

Header membuat output terminal lebih mudah dipahami. Tanpa header, pengguna mungkin tidak tahu program apa yang sedang berjalan atau data apa yang perlu dimasukkan.

Garis seperti === atau --- bukan perintah khusus. Itu hanya teks yang dicetak agar tampilan terminal terlihat lebih terstruktur.

Tips tampilan terminal

  • Gunakan judul yang jelas.
  • Gunakan garis pemisah secukupnya.
  • Jangan membuat output terlalu ramai.
  • Pastikan prompt input mudah dipahami.

Menggabungkan Input dan Casting

Pada langkah ini, program mulai menyerupai form digital sederhana. Pengguna memasukkan empat data. Dua data berupa teks, dua data lainnya perlu menjadi angka.

Pemetaan tipe data

  • nama_lengkap → string.
  • usia → integer.
  • rencana_keuangan → string.
  • target_nominal → integer.

Kalau kamu lupa melakukan casting pada target nominal, data tetap menjadi string. Akibatnya, data akan sulit dipakai untuk perhitungan bonus seperti estimasi tabungan per bulan.

Kenapa format penting?

Dalam aplikasi finansial, angka harus mudah dibaca. Salah membaca digit bisa menyebabkan salah paham, terutama pada nominal besar.

  • Target nominal berubah dan tetap terformat rapi.
  • Tidak ada error ketika input angka ditulis dengan format yang benar.

Jika output masih menampilkan data lama, cek apakah program sudah dijalankan ulang atau input simulator sudah diubah pada editor yang tepat.

Edge Case

Edge case adalah kondisi input yang tidak biasa atau tidak sesuai harapan. Contohnya, program meminta angka, tetapi pengguna memasukkan kata-kata.

Pada level dasar, kita mengenali dulu bentuk error-nya. Di level lanjutan, program bisa dibuat lebih kuat dengan validasi input, pengulangan, atau pesan peringatan yang lebih ramah.

Pesan penting

Error bukan berarti kamu gagal. Error adalah informasi tentang bagian program yang perlu diperiksa.

Membaca Target Output

Target terminal membantu kamu membandingkan hasil program. Kamu tidak harus menyalin setiap garis secara sama persis, tetapi struktur informasinya harus jelas.

Yang wajib terlihat

  • Header program.
  • Prompt input untuk empat data.
  • Ringkasan profil nasabah.
  • Nama, usia, rencana, dan target nominal.
  • Target nominal tampil dengan format yang mudah dibaca.

Jika output berantakan, cek kembali urutan print(), label teks, dan penggunaan f-string.

Debugging yang Terarah

Debugging sebaiknya dilakukan dengan urutan yang jelas. Jangan langsung menghapus semua kode. Baca gejala error, cari baris yang berhubungan, lalu perbaiki bagian kecil yang kemungkinan menjadi penyebab.

Urutan cek

  1. Baca pesan error atau gejala output.
  2. Cek baris input dan casting.
  3. Cek nama variabel.
  4. Cek tanda kutip dan huruf f pada f-string.
  5. Jalankan ulang setelah memperbaiki.

Semakin sering kamu membaca error, semakin mudah kamu mengenali pola masalahnya.

Checklist Berhasil

Output minimum adalah target wajib sebelum mencoba challenge. Kalau semua checklist sudah terpenuhi, berarti kamu sudah memahami inti sesi: input, variabel, tipe data, casting, dan output.

Jangan lompat terlalu cepat

Pastikan program utama berjalan dulu. Jika langsung menambah fitur bonus saat program dasar masih error, debugging akan lebih sulit.

Setelah output minimum aman, kamu boleh menambah fitur seperti estimasi tabungan per bulan.

Extension Challenge

Challenge ini menghubungkan materi sesi 2 dengan perhitungan yang akan berguna pada sesi berikutnya. Program meminta durasi dalam bulan, lalu menghitung estimasi tabungan per bulan.

Rumus

tabungan_per_bulan = target_nominal / durasi_bulan

Input durasi harus lebih besar dari 0. Jika durasi bernilai 0, Python tidak bisa melakukan pembagian dan akan menghasilkan ZeroDivisionError.

Catatan

Di aplikasi nyata, developer perlu menambahkan validasi agar pengguna tidak bisa memasukkan durasi 0 atau input yang tidak sesuai.

Refleksi Akhir

Hari ini kamu sudah membuat program yang lebih interaktif dibanding sesi sebelumnya. Program tidak hanya menampilkan data yang sudah ditulis di kode, tetapi juga menerima data baru dari pengguna.

Yang sudah dipelajari

  • Alur Input → Process → Output.
  • input() untuk menerima ketikan pengguna.
  • Nama variabel dengan gaya snake_case.
  • Tipe data str, int, dan float.
  • Type casting dengan int() dan float().
  • Keamanan data saat memakai data latihan.
  • Testing dan debugging dasar.

Di sesi berikutnya, konsep ini akan dipakai untuk membuat perhitungan yang lebih bermakna. Jadi, pastikan kamu paham kenapa angka dari input perlu dikonversi sebelum dihitung.
