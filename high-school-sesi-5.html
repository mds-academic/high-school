Program Mulai Bisa Memilih

Di Bab 1, program yang kamu buat biasanya mengikuti alur Input → Process → Output. Semua baris dijalankan dari atas ke bawah.

Di sesi ini, alurnya berubah sedikit. Program tetap membaca dari atas, tetapi saat bertemu kondisi, program akan mengecek: apakah kondisi ini benar atau salah?

Jika benar, program masuk ke cabang pertama. Jika salah, program masuk ke cabang alternatif. Inilah dasar dari control flow.

Contoh nyata

Kalau saldo cukup, pembelian bisa lanjut. Kalau saldo belum cukup, aplikasi menampilkan kekurangan saldo. Ini konsep yang sama dengan if dan else.

Kondisi Selalu Dievaluasi

Di Python, kondisi seperti usia_user >= batas_usia akan dievaluasi menjadi nilai logika: True atau False.

Kalau hasilnya True, baris di dalam blok if akan dijalankan. Kalau hasilnya False, Python akan melewati blok if dan mencari else.

Cara membaca

usia_user >= batas_usia dibaca: “apakah usia user lebih besar atau sama dengan batas usia?”

Latihan kecil ini membantu kamu melihat bahwa percabangan sebenarnya dimulai dari pertanyaan logis yang sangat spesifik.

Membuat Kalimat Logika

Sebelum menulis Python, kita bisa melatih logika dengan kalimat sehari-hari. Polanya adalah “Kalau kondisi terjadi, maka lakukan sesuatu.”

Contoh: kalau saldo cukup, maka pembelian lanjut. Kalau saldo belum cukup, maka sistem menampilkan informasi kekurangan saldo.

Di kode Python, kalimat seperti ini akan berubah menjadi struktur if dan else. Jadi, aktivitas ini bukan sekadar pemanasan; ini adalah cara berpikir sebelum coding.

Tips

Dari Flowchart ke Kode

Flowchart membantu kamu melihat bentuk keputusan secara visual. Pada project ini, flowchart-nya sederhana: program menerima usia, mengecek apakah usia memenuhi batas, lalu memilih output.

Kotak “usia ≥ 17?” adalah titik keputusan. Di sana program tidak langsung mencetak semuanya. Program bertanya dulu: kondisi ini benar atau salah?

Mapping ke Python

Cabang True menjadi blok if. Cabang False menjadi blok else. Panah pada flowchart berubah menjadi urutan baris kode.

Simbol Kecil, Dampaknya Besar

Operator pembanding menentukan bagaimana program membaca kondisi. Karena itu, pilih operator sesuai aturan logika yang kamu mau.

Untuk project ini, kita memakai >=, bukan hanya >. Alasannya: input usia 17 harus ikut masuk ke cabang “memenuhi batas simulasi”.

Hati-hati

> artinya lebih besar dari. Jadi 17 tidak lolos jika kondisinya usia > 17. Kalau mau 17 ikut lolos, gunakan >=.

Assignment vs Comparison

= dipakai saat kamu ingin menyimpan nilai. Misalnya batas_usia = 17 berarti variabel batas_usia berisi angka 17.

== dipakai saat kamu ingin membandingkan. Misalnya usia_user == 17 berarti Python mengecek apakah nilai usia_user sama dengan 17.

Cara mengingat

Satu sama dengan untuk menyimpan. Dua sama dengan untuk bertanya “apakah sama?”

Pada sesi ini, kamu paling sering memakai >=, tetapi memahami == penting karena nanti akan dipakai di login terminal.

Menguji Nilai Batas

Testing tidak cukup hanya mencoba angka yang jauh dari batas. Untuk validator usia, angka yang paling penting justru angka batasnya: 17.

Kalau aturan simulasi menyebut “17 atau lebih”, maka usia 17 harus lolos. Karena itu operator yang tepat adalah >=.

Test case utama

  • 16 → cabang else
  • 17 → cabang if
  • 18 → cabang if

Testing seperti ini disebut boundary testing. Developer menggunakannya untuk mencari bug di batas aturan.

Aturan Sintaks yang Wajib Rapi

Python memakai indentasi untuk membaca struktur kode. Artinya, spasi bukan hanya soal tampilan. Spasi menentukan baris mana yang masuk ke dalam cabang if atau else.

Setelah baris if kondisi:, baris di bawahnya harus masuk menjorok, biasanya 4 spasi. Setelah else:, baris di bawahnya juga harus menjorok.

Error yang sering muncul

Jika titik dua hilang, kamu akan melihat SyntaxError. Jika indentasi salah, kamu bisa melihat IndentationError.

Mencoba Cabang Pertama

Editor ini adalah versi ringkas dari project utama. Program meminta usia, lalu mengecek apakah usia tersebut lebih besar atau sama dengan 17.

Saat kamu menjalankan input 16, kondisi usia >= 17 bernilai False, jadi output berasal dari else. Saat kamu menjalankan input 17 atau 18, kondisi bernilai True, jadi output berasal dari if.

Yang harus diamati

Program yang sama bisa menampilkan output berbeda hanya karena inputnya berubah.

Karena kondisi salah, Python melewati blok if dan menjalankan blok else. Maka outputnya adalah “Belum memenuhi batas simulasi.”

Mengambil Input Angka

Karena usia perlu dibandingkan dengan angka 17, input harus berbentuk integer. Itulah alasan kita memakai int(input()).

Kalau hanya memakai input(), Python akan menyimpan jawaban sebagai string. String tidak cocok untuk dibandingkan dengan angka integer dalam logika usia.

Format input

Tulis 17, bukan 17 tahun atau tujuh belas. Format salah akan memunculkan ValueError.

Cabang if

Blok if hanya berjalan ketika kondisinya benar. Pada kode ini, kondisi yang dicek adalah usia_user >= batas_usia.

Jika inputnya 17 atau lebih, Python masuk ke blok if dan menjalankan semua baris yang menjorok di bawahnya.

Jika inputnya 16, kondisi bernilai False. Karena di slide ini belum ada else, program tidak mencetak status alternatif. Itu sebabnya cabang else penting.

Kenapa 17 harus dites?

Karena bug sering muncul di titik batas. Jika kamu keliru memakai >, maka 17 akan masuk jalur yang salah.

Melacak Program Baris demi Baris

Trace table membantu kamu membaca program seperti debugger manual. Kamu mencatat input, hasil kondisi, cabang yang dipilih, dan output.

Dengan cara ini, kamu tidak hanya tahu hasil akhir, tetapi juga tahu alasan program mengambil jalur tertentu.

Kapan trace table berguna?

Saat output program terasa aneh, trace table bisa membantu menemukan apakah masalahnya ada pada input, kondisi, operator, atau output.

SyntaxError: expected ':'

Setiap baris if, elif, dan else harus diakhiri dengan titik dua. Titik dua memberi tahu Python bahwa blok kode baru akan dimulai.

Jika titik dua hilang, Python tidak bisa memahami struktur percabangan dan program berhenti sebelum menjalankan output.

Perbaikan

Ubah if usia_user >= 17 menjadi if usia_user >= 17:.

IndentationError

Indentasi menentukan baris mana yang masuk ke dalam blok if atau else. Jika satu baris menjorok 4 spasi dan baris berikutnya hanya 2 spasi, Python bisa bingung membaca struktur.

Untuk menghindari bug ini, gunakan indentasi 4 spasi secara konsisten. Banyak editor akan membantu otomatis, tetapi kamu tetap perlu mengeceknya.

Tips cepat

Semua baris yang berada dalam blok yang sama harus punya posisi menjorok yang sama.

Membaca ValueError

ValueError muncul ketika nilai yang dimasukkan tidak cocok dengan proses yang diminta. Dalam contoh ini, int() hanya bisa menerima teks angka seperti 17, bukan kata tujuh belas.

Untuk sesi ini, solusi paling sederhana adalah memasukkan angka murni. Di sesi berikutnya, kamu akan belajar cara membuat program lebih tahan error dengan validasi yang lebih baik.

Format yang aman

Gunakan 16, 17, atau 18. Jangan menambahkan kata “tahun” di input.

Logic Error Lebih Licin

Logic error terjadi ketika program bisa berjalan, tetapi hasilnya tidak sesuai aturan yang diinginkan.

Contoh di slide ini tidak memunculkan SyntaxError. Kodenya sah. Namun, untuk aturan “17 atau lebih”, operator > salah karena tidak menyertakan usia 17.

Solusi

Ganti kondisinya menjadi usia_user >= 17, lalu uji lagi dengan input 16, 17, dan 18.
