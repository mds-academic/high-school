Baca Fungsi Final Setelah Tugas Selesai

Referensi untuk membaca ulang — tuntaskan TODO sendiri terlebih dahulu

import re

def mesin_cuci_teks(teks_mentah):
    if not isinstance(teks_mentah, str):
        return ""
    teks = teks_mentah.lower()
    teks = re.sub(r"[^a-zA-Z0-9\s]", " ", teks)
    teks = re.sub(r"\s+", " ", teks).strip()
    kata_kata = teks.split()
    kata_baku = [KAMUS_SLANG.get(k, k) for k in kata_kata]
    return " ".join(kata_baku)

Fungsi ini memerlukan KAMUS_SLANG dari setup pada slide sebelumnya.

Kenapa teks perlu dibersihkan dulu?

Rian dan Dian sedang menyiapkan chatbot koperasi sekolah. Mereka sadar pertanyaan pengguna tidak selalu ditulis rapi: huruf besar-kecil bercampur, ada banyak tanda baca, dan singkatan seperti min, brp, atau tf.

Sebelum membuat program yang mengenali kata kunci, kita perlu menyamakan bentuk teks lebih dulu. Proses ini disebut text preprocessing.

Hasil akhir kita adalah fungsi Python mesin_cuci_teks(teks_mentah) yang bisa diuji secara berulang dengan data fiktif.

Apa yang perlu kamu tunjukkan?

Tidak cukup hanya menuliskan fungsi. Kamu perlu bisa menjelaskan kenapa setiap baris digunakan, menunjukkan output sebelum dan sesudah, lalu menemukan bug ketika hasil tidak sesuai.

Komponen yang digunakan: modul re, string, list, dictionary, fungsi, dan for. Kamu pernah mengenal Regex sebelumnya; sekarang dipakai dalam alur yang lebih utuh.

Mengatur waktu praktik

Kita akan melewati konsep secara ringkas dan menghabiskan sebagian besar waktu di Google Colab. Materi dibagi agar kamu tahu kapan harus berpindah dari memahami konsep, mengerjakan TODO, sampai memastikan hasil uji.

Apa yang berubah setelah pembersihan?

Pencocokan teks dengan aturan sederhana dapat peka terhadap perbedaan huruf, tanda baca, dan spasi. Saldo dan saldo bisa dianggap berbeda jika program membandingkannya secara langsung.

Bayangkan kalimat “HALO!!! min, cek saldo...” diubah menjadi “halo admin cek saldo”. Bentuknya lebih konsisten, sehingga tahap berikutnya lebih mudah mencari kata yang relevan.

Mengapa urutannya seperti ini?

Kita mengubah huruf ke lowercase terlebih dahulu, supaya kamus slang tidak perlu menyimpan bentuk MIN, Min, dan min satu per satu.

Setelah tanda baca diganti spasi, whitespace perlu dirapikan. Baru kemudian teks dipecah menjadi daftar kata dan dicocokkan dengan dictionary. Jika urutan diacak, hasilnya berpotensi berbeda.

Apa arti case-sensitive?

Python membedakan huruf besar dan kecil ketika membandingkan string secara langsung. Contoh "Saldo" == "saldo" menghasilkan False. Dengan normalisasi, kedua bentuk tersebut dapat menjadi "saldo".

.lower() perlu diterapkan pada input bertipe string. Jika input angka seperti 123, Python tidak punya metode string ini; proyek akan mengecek tipe dahulu.

Kenapa replacement-nya spasi?

Pola r"[^a-zA-Z0-9\s]" mencari karakter di luar kelompok huruf Latin, digit dan whitespace. Fungsi re.sub() mengganti karakter yang cocok menjadi teks pengganti.

Kita memakai " " agar halo?min berubah menjadi halo min. Kalau diganti string kosong "", hasilnya halomin.

Ini pola sederhana untuk latihan. Simbol tertentu mungkin bermakna penting pada data finansial, jadi jangan langsung menggunakan hasilnya untuk menghitung transaksi.

Bedakan kompresi dan trimming

re.sub(r"\s+", " ", teks) mengubah rangkaian spasi, tab, atau newline menjadi satu spasi. Setelah itu, .strip() membuang whitespace di paling depan dan paling belakang.

Contohnya, " sy tdk " belum menjadi "saya tidak"; setelah merapikan spasi, kita baru memperoleh "sy tdk". Perubahan ke kata baku dilakukan pada tahap kamus slang.

Mengapa get(kata, kata) penting?

Dictionary menyimpan pasangan kunci dan nilai. Saat sebuah kata ditemukan, get() mengembalikan terjemahan bakunya. Jika tidak ditemukan, argumen kedua dipakai sebagai hasil cadangan: kata dibiarkan seperti semula.

Inilah alasan "gakk" dan "sdh" tetap muncul pada output proyek dasar. Mereka belum ada di dictionary awal. Tidak ada AI yang otomatis menebak bentuk kata terdekat.

Baca kode dari kiri ke kanan

.split() memecah kalimat menjadi list, misalnya ["min", "brp", "biaya", "tf"].

[... for k in kata_kata] memproses semua kata. Dictionary mengubah yang ditemukan dan mempertahankan yang tidak ditemukan.

Terakhir, " ".join(...) menggabungkan list menjadi kalimat dengan satu spasi sebagai pemisah.

Periksa daftar kunci dulu

Sebuah dictionary tidak melakukan koreksi ejaan berdasarkan bunyi atau kemiripan bentuk. "gak" dan "gakk" adalah dua kunci berbeda.

Kamu boleh menambah "gakk": "tidak" sebagai challenge setelah fungsi utama lulus tes. Namun, untuk checkpoint resmi kita mempertahankan dictionary dasar dari Teacher Project.

Dua masalah, dua penyebab

Pertama, tidak ada 0-9 dalam kelompok yang dipertahankan, sehingga digit pada 25000 justru dibuang.

Kedua, tanda tanya di antara halo dan min diganti string kosong; kata menempel menjadi halomin.

Solusinya adalah re.sub(r"[^a-zA-Z0-9\s]", " ", teks), lalu rapikan whitespace. Jangan menganggap semua penghapusan simbol aman untuk nilai uang atau identitas.

Tiga parameter re.sub()

Fungsi re.sub(pattern, replacement, string) membaca pola, mencari kecocokan pada string, lalu menggantinya. Pada tugas ini, pola adalah r"[^a-zA-Z0-9\s]"; pengganti adalah satu spasi; dan string sumbernya adalah variabel teks.

Setelah melengkapi kode, coba input "halo?min saldo 25000". Angka tidak boleh hilang, tetapi hasil masih mungkin punya beberapa spasi jika ada simbol berurutan. Spasi tersebut dirapikan pada TODO 3.

Checkpoint sebelum lanjut

Tidak perlu menghafal hasil per karakter; fokus pada tujuan perbaikan. Kalau angka hilang, cek rentang 0-9. Kalau dua kata menempel, cek replacement. Kalau program error pada integer, cek penjagaan tipe input.

Setelah yakin dua tahap ini benar, lanjutkan ke proses yang membuat spasi rapi dan kata-kata gaul menjadi baku.

Mengapa TODO 3 setelah TODO 2?

Satu tanda baca diganti menjadi satu spasi, tetapi simbol yang berulang seperti ??? akan menghasilkan beberapa spasi berturut-turut.

\s+ cocok dengan satu atau lebih whitespace. .strip() membuang sisa whitespace di tepi. Di tugas ini, hasil harus berupa string yang bersih dan siap dipisah menjadi list kata.

Mengapa list comprehension dipakai?

Proses ini harus dilakukan untuk setiap kata di dalam list. List comprehension menulis perulangan dengan ringkas dan menghasilkan list baru.

Jika kata ditemukan dalam dictionary, nilai pengganti dipakai. Jika tidak, kata asli tetap. Kemudian " ".join(...) menyusun ulang list menjadi satu kalimat.

Pembersihan teks adalah fondasi, bukan bukti bahwa komputer sudah memahami semua maksud pengguna.
