Bentuk Python-nya

Tabel tadi bisa ditulis sebagai list of dictionary.

# List besar berisi beberapa dictionary
database_portofolio = [
    {"id": 1, "nama": "Emas"},
    {"id": 2, "nama": "Laptop"},
    {"id": 3, "nama": "Sepeda"}
]

Perhatikan tanda

[] untuk list. {} untuk dictionary. Key seperti "id" dan "nama" ditulis sebagai string.

Akses Data dengan Key

Untuk mengambil isi dictionary, panggil key-nya.

aset["id"]

Tambah Record dengan append()

.append() menambahkan item baru ke akhir list.

# Membuat record baru
aset_baru = {"id": 4, "nama": "Reksa Dana"}

# Menambahkan record ke database
database_portofolio.append(aset_baru)

Kenapa ID 4?

Karena ID 1, 2, dan 3 sudah dipakai. ID baru sebaiknya unik.

Kenapa Butuh Struktur Data?

Kalau data bertambah, variabel terpisah seperti aset_1, aset_2, dan seterusnya akan sulit dirawat.

Dengan list dan dictionary, kita bisa menyimpan data yang banyak dalam pola yang sama. Kode juga lebih mudah dibaca dan lebih siap dikembangkan.

Istilah Kunci

List menyimpan banyak item. Dictionary menyimpan data berpasangan: key dan value. Record adalah satu baris data lengkap.

Saat beberapa dictionary dimasukkan ke dalam satu list, kita mendapatkan bentuk database mini.

Data Lebih Mudah Dibaca sebagai Tabel

Walaupun output Python berbasis teks, kita tetap bisa membuat tampilannya rapi. ID dan nama membantu user melihat data dengan cepat.

ID bukan hanya dekorasi. ID adalah identitas unik yang membuat record tidak mudah tertukar.

Membaca dari Luar ke Dalam

Baca struktur data dari wadah paling luar: list besar. Di dalamnya ada beberapa dictionary. Setiap dictionary adalah satu record aset.

Jika kurung dan koma rapi, Python lebih mudah membaca data tersebut.

Key Harus Tepat

Dictionary bekerja seperti data berlabel. Jika ingin nama aset, panggil aset["nama"]. Jika ingin ID, panggil aset["id"].

Kesalahan umum: lupa tanda kutip atau memanggil key yang belum ada.

List Memilih Posisi, Dictionary Memilih Key

database_portofolio[0] mengambil record pertama dari list. Setelah itu, aset_pertama["nama"] mengambil value dari key nama.

Ini pola penting: list dipakai untuk memilih posisi, dictionary dipakai untuk memilih label data.

Loop Membaca Data Otomatis

for loop membantu program membaca item dalam list satu per satu. Pada sesi ini, setiap item kita sebut aset.

Kalau ada record baru, loop tetap bisa membacanya tanpa menambah banyak baris print manual.

Dari Data ke Output

Program dimulai dari list of dictionary. Loop membaca setiap dictionary, mengambil key yang dibutuhkan, lalu mencetaknya menjadi baris tabel.

Alur ini sederhana, tetapi fondasinya kuat untuk aplikasi CLI yang lebih kompleks.

append() untuk Mengembangkan Data

Record baru tetap berbentuk dictionary agar format data konsisten. Jangan mencampur record dictionary dengan teks biasa di dalam list yang sama.

Setelah append(), Loop Membaca Lagi

Program ini menambah satu record baru, lalu loop mencetak semua record. Karena record baru ditambahkan sebelum loop, output akan menampilkan empat baris aset.
