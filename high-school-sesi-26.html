Buat laporan_keuangan.csv

FILE_CSV = "laporan_keuangan.csv"

def buat_laporan_csv(data_transaksi):
    header = ["Tanggal", "Keterangan", "Tipe", "Nominal"]
    with open(FILE_CSV, "w", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        writer.writerow(header)
        writer.writerows(data_transaksi)

Dari Buku Kas ke Laporan Tabel

Pada Lesson 25, kamu membuat catatan transaksi menggunakan file TXT. Format itu sudah membantu menyimpan riwayat, tetapi masih berupa teks biasa. Jika guru koperasi ingin mengurutkan transaksi berdasarkan tanggal atau membuat grafik dari angka nominal, data berkolom akan lebih praktis.

CSV atau Comma-Separated Values adalah format teks untuk menyimpan tabel sederhana. Melalui modul csv bawaan Python, kita dapat menulis dan membaca data dengan struktur kolom yang konsisten.

Target Lesson 26: membuat laporan_keuangan.csv berisi Tanggal, Keterangan, Tipe, dan Nominal; membaca kembali hasilnya; menguji file di spreadsheet; serta mencoba analisis saldo dari data simulasi.

Apa yang Kurang dari TXT?

TXT tidak salah. File itu cocok untuk mencatat teks bebas atau log sederhana. Tetapi format transaksi yang kita buat pada Sesi 25 hanya memakai tanda pipa (|) sebagai pemisah yang kita susun sendiri.

Untuk mengolah data sebagai tabel di spreadsheet, setiap record perlu memiliki struktur field yang jelas: tanggal, keterangan, tipe, dan nominal. CSV menyediakan cara yang lazim untuk memindahkan data tabular dari satu aplikasi ke aplikasi lain.

Kita tidak hanya mengganti nama berkas dari .txt menjadi .csv. Yang penting adalah isi file ditulis menurut aturan format CSV, bukan sekadar berganti ekstensi.

Kenali Isi File CSV

Baris pertama adalah header. Empat nama kolom tersebut membantu program maupun pengguna mengerti arti setiap nilai. Baris berikutnya adalah row atau record transaksi.

Delimiter pada contoh ini adalah koma. Penanda ini memisahkan nilai satu kolom dengan kolom lain. Pada beberapa sistem atau konfigurasi lokal, pemisah CSV bisa berbeda, tetapi dalam proyek Python ini kita menggunakan konfigurasi default modul csv yang memakai koma.

Nominal di file contoh ditulis sebagai angka tanpa pemisah ribuan. Ini disengaja supaya lebih mudah dibaca kembali sebagai data numerik. Pemformatan mata uang dapat dilakukan pada tahap tampilan.

CSV Adalah Struktur Tabel

Tabel ini memperlihatkan data yang sama dengan CSV mentah, tetapi setiap nilai berada dalam kolom yang sesuai. Contohnya, seluruh nilai pemasukan dan pengeluaran ada di kolom Nominal, sedangkan arah transaksi ada di kolom Tipe.

Dengan struktur yang konsisten, kita dapat memfilter hanya transaksi KELUAR atau menghitung total berdasarkan kategori. Jika urutan kolom berubah tanpa mengubah header, laporan bisa salah dibaca.

Untuk praktik hari ini, setiap baris data harus mempunyai empat nilai sesuai urutan header: Tanggal, Keterangan, Tipe, Nominal.

Kenalan dengan Modul csv

Baris import csv memuat modul standar Python untuk mengelola CSV. Kamu akan menggunakan dua kemampuan dasar: membuat file laporan dan membaca kembali data laporan tersebut.

csv.writer(f) menghasilkan objek penulis yang tahu cara mengubah List menjadi baris CSV. csv.reader(f) melakukan kebalikannya: mengambil baris dalam file dan mengembalikannya sebagai List string.

Kita juga memakai os.path.exists() dari sesi sebelumnya untuk memeriksa apakah file laporan sudah tersedia sebelum membacanya.

Dari List Python ke CSV

Teacher Project S26 menggunakan struktur List of Lists, yaitu sebuah List yang berisi beberapa List lain. Setiap List di bagian dalam menggambarkan satu transaksi.

Pada contoh pertama, urutan nilainya adalah tanggal 2026-10-25, keterangan Setoran Uang Saku, tipe MASUK, dan nominal 500000. Urutan ini harus sama dengan urutan header yang nanti ditulis.

Kita menggunakan bilangan integer untuk nominal di Python ketika data disiapkan. Ketika CSV dibaca kembali memakai csv.reader(), nilai tersebut umumnya muncul sebagai string dan perlu dikonversi lagi sebelum dihitung.

writerow() dan writerows()

Method writer.writerow(data) menuliskan satu record CSV. Karena header hanya satu baris, kita biasanya menuliskannya menggunakan method ini.

Method writer.writerows(kumpulan_data) menuliskan banyak record sekaligus. Inilah yang digunakan dalam Teacher Project S26 untuk mengekspor List of Lists yang sudah tersedia.

Kamu juga bisa memakai for untuk mengulang writer.writerow() satu per satu, seperti starter code pada modul. Keduanya valid. Pilih salah satu sesuai struktur data dan tujuan pembelajaran.

Jangan Lupa newline dan encoding

Saat menulis CSV menggunakan modul csv, gunakan newline="" pada open(). Ini membiarkan modul CSV mengatur karakter akhir baris secara konsisten dan mencegah masalah baris kosong ganda, terutama pada beberapa konfigurasi Windows.

encoding="utf-8" menentukan encoding teks yang dipakai. File CSV tidak otomatis menjadi terenkripsi karenanya.

Mengapa mode w sekarang digunakan? Berbeda dari log transaksi TXT yang ditambah setiap hari, proyek ini membuat laporan hasil ekspor yang baru dari dataset yang tersedia. Karena itu, mode w dipakai untuk mengganti isi laporan sebelumnya. Jangan gunakan nama file yang sama jika laporan lama perlu disimpan terpisah.

Project Step 2: Baca File CSV

Fungsi pembaca tidak menulis ulang laporan. Ia pertama-tama memeriksa keberadaan file, lalu membuka laporan dalam mode r.

csv.reader(f) menghasilkan iterator. Kita menggunakan for baris in reader untuk menelusuri setiap baris, termasuk header. Setiap baris adalah List string, sehingga dapat ditampilkan dengan print(baris).

Jika laporan belum dibuat, program menampilkan pesan peringatan. Siswa perlu menjalankan fungsi ekspor terlebih dahulu atau memeriksa nama file pada variabel FILE_CSV.

Perhatikan Output csv.reader

Saat kamu menuliskan integer 500000 ke CSV, nilai itu menjadi karakter dalam file teks. Karena itu, ketika dibaca dengan csv.reader(), elemen yang tampil adalah string "500000".

Menambahkan dua string tidak sama dengan menambahkan dua angka. Contoh "500000" + "35000" menghasilkan penggabungan teks, bukan total pengeluaran atau pemasukan.

Untuk melakukan perhitungan, gunakan int(baris[3]) jika data numerik valid dan kolom nominal memang berada di indeks keempat. Pada bagian pengayaan, kita akan memakai DictReader agar akses kolom bisa menggunakan nama "Nominal".

csv.reader vs csv.DictReader

Dengan csv.reader(), setiap baris adalah List string. Kita mengakses kolom berdasarkan urutannya: indeks 0 untuk Tanggal, 1 untuk Keterangan, 2 untuk Tipe, dan 3 untuk Nominal.

Dengan csv.DictReader(), setiap baris menjadi mapping yang bisa diakses memakai nama kolom. Baris header digunakan sebagai kunci, sehingga baris["Nominal"] lebih mudah dipahami daripada baris[3].

Teacher Project S26 menggunakan keduanya: reader untuk melihat isi file, lalu DictReader untuk latihan analisis. Penggunaan DictReader dan perhitungan saldo bisa dikerjakan setelah bagian ekspor-baca dasar selesai.

Mini Check: Prediksi Hasil

Satu List dengan tiga nilai akan menjadi satu baris CSV dengan tiga field. Pada konfigurasi default modul csv Python, pemisah field adalah koma. Karena itu, ketiga nilai dipisahkan oleh tanda koma.

Saat file benar-benar dibuat, writer juga mengelola karakter akhir baris sesuai dialect CSV yang dipakai. Namun, kamu tidak perlu menambahkan \n manual ke setiap field seperti pada TXT sesi sebelumnya.

Aktivitas ini menguji pemahaman hubungan antara struktur List dan bentuk teks di file, bukan sekadar hafalan nama method.

Koma di Dalam Keterangan

Jika keterangan transaksi mengandung koma, merangkai CSV secara manual menggunakan tanggal + "," + keterangan ... dapat membuat data salah terbagi.

Modul csv.writer() dapat menangani field yang memiliki delimiter. Pada contoh ini, keterangan Beli Buku, Pensil akan dikelilingi tanda kutip ganda di baris CSV, sehingga pembaca CSV yang benar tetap menganggapnya satu field.

Saat membaca kembali file dengan csv.reader(), keterangan tersebut tetap berada dalam satu elemen List. Ini contoh mengapa menggunakan library lebih aman daripada mengandalkan split(",") untuk semua kasus.

Detektif Bug: Baris Kosong Ganda

Di beberapa lingkungan, terutama Windows, pengelolaan karakter akhir baris dapat menyebabkan munculnya baris kosong tambahan ketika kode CSV ditulis tanpa pengaturan newline="".

Solusi yang direkomendasikan adalah membuka file dengan newline="", lalu membiarkan modul csv menangani penulisan akhir baris. Parameter ini adalah bagian dari fungsi open(), bukan dari csv.writer().

Setelah memperbaiki, ekspor ulang laporan, buka file, dan pastikan setiap record menempati satu baris tanpa baris kosong yang tidak diinginkan.

Detektif Bug: Encoding dan Header

Karakter yang tampak aneh di spreadsheet bisa berasal dari encoding yang tidak cocok antara proses ekspor dan impor. Gunakan UTF-8 pada tahap penulisan serta perhatikan pengaturan pembacaan di aplikasi tujuan.

Header berulang merupakan masalah berbeda. Jika kamu terus menjalankan ekspor penuh dalam mode a dan setiap kali menulis header, file dapat memuat beberapa baris judul yang tercampur dengan transaksi. Karena proyek ini membuat satu laporan penuh, Teacher Project memakai mode w.

Perhatikan perbedaan tujuan dari Lesson 25: log transaksi biasanya ditambah dari waktu ke waktu; file hasil ekspor bisa dibuat ulang dari dataset sumber. Pilihan mode harus mengikuti kebutuhan data.

Testing Wajib: Validasi File

Membuat CSV yang benar berarti data tidak hanya bisa ditulis, tetapi juga bisa dibaca kembali tanpa kehilangan makna. Cek jumlah kolom, jumlah record, urutan header, dan nilai nominal.

Dalam Teacher Project S26, minimal semua transaksi muncul kembali ketika baca_laporan_csv() dijalankan. Gunakan beberapa data contoh dan pastikan output terminal cocok dengan List sumber.

Untuk edge case, gunakan satu keterangan dengan koma. Jika csv.reader() mengembalikan empat elemen sesuai header, berarti kolom tetap terjaga.

Analisis Lanjutan dengan DictReader

Bagian ini merupakan latihan lanjut yang juga tersedia dalam Teacher Project S26. csv.DictReader() menggunakan header untuk menentukan nama field.

Saat baris["Tanggal"] dibaca, kita mendapat teks tanggal transaksi. Saat baris["Nominal"] dibaca, hasil awalnya string; gunakan int() agar dapat diolah secara matematis.

Gunakan data dengan header yang benar dan nominal valid. Jika kolom tidak ada, akses berdasarkan nama dapat memicu KeyError. Jika nominal bukan angka, int() dapat memicu ValueError. Ini mengingatkan kembali konsep debugging dari Semester 1.

Hitung Saldo dari Data CSV

Agar laporan berguna, kita perlu membedakan pemasukan dan pengeluaran. Kode menyiapkan dua penampung bernilai nol: total_masuk dan total_keluar.

Saat loop membaca setiap baris, nominal dikonversi menjadi integer. Jika tipe transaksi MASUK, jumlahnya ditambahkan ke total pemasukan. Jika KELUAR, jumlahnya ditambahkan ke total pengeluaran.

Setelah seluruh baris dibaca, saldo dihitung sebagai total_masuk - total_keluar. Kode ini bergantung pada label tipe yang konsisten; MASUK tidak sama dengan masuk jika tidak dinormalisasi.

Simulasi Saldo

Simulator memakai operasi yang sama dengan kode Python: pemasukan dikurangi pengeluaran. Contoh dari empat transaksi Teacher Project pertama memiliki pemasukan Rp500.000 + Rp250.000 = Rp750.000 dan pengeluaran Rp35.000 + Rp120.000 = Rp155.000. Jadi, saldo akhirnya Rp595.000.

Coba ubah nilai pengeluaran agar lebih besar daripada pemasukan. Saldo akan negatif. Itu adalah hasil matematika yang mungkin terjadi dalam simulasi dan perlu dijelaskan dengan benar, bukan otomatis dianggap kesalahan Python.

Komponen interaktif ini hanya latihan menghitung, bukan pengganti file CSV. Di Colab, kamu tetap perlu membaca transaksi satu per satu dari file untuk mendapatkan nilai total.

Contoh Ringkasan dari Teacher Project

Jangan langsung mempercayai hasil program tanpa pembanding. Hitung total pemasukan dan pengeluaran secara manual untuk satu dataset kecil, lalu cocokkan hasilnya dengan output Python.

Dalam contoh pertama Teacher Project S26, total pemasukan adalah Rp750.000 dan total pengeluaran Rp155.000. Dengan rumus saldo akhir, hasilnya Rp595.000.

Teacher Project juga menyediakan dataset latihan analisis yang berbeda pada cell berikutnya. Jika kamu memakai dataset kedua itu, jumlah dan saldo yang dihasilkan tentu berbeda. Pastikan kamu tahu dataset mana yang sedang dihitung sebelum menyimpulkan program salah.

Privasi saat Membagikan CSV

Kemudahan CSV menjadi keunggulan sekaligus risiko. Aplikasi lain dapat membaca CSV, sehingga file yang jatuh ke pihak yang tidak berhak juga bisa dibuka.

CSV standar tidak menyediakan enkripsi atau pembatasan akses bawaan. Simpan file latihan dengan data simulasi. Jangan menuliskan nomor rekening asli, kata sandi, identitas pribadi, atau rincian transaksi sensitif.

Saat membagikan melalui Google Drive atau LMS, ikuti izin akses yang diwajibkan guru. Mengubah pengaturan menjadi dapat dilihat siapa saja tidak selalu diperlukan.

Mini Review: TXT atau CSV?

Pilih format berdasarkan cara data digunakan. TXT dapat dipakai untuk catatan teks yang sederhana atau mudah dibaca manusia. CSV lebih sesuai jika data punya struktur tabel yang konsisten dan ingin digunakan dalam spreadsheet.

CSV bukan pengganti semua jenis file. Format ini tidak menyimpan fitur spreadsheet seperti formula, warna sel, atau banyak sheet. Ia menyimpan nilai-nilai tabular secara sederhana.

Hal yang paling penting: kamu memahami bagaimana format file memengaruhi tahap pengolahan data setelahnya.
