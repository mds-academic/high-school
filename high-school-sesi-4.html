IPO dalam Project Payroll

Project ini mengikuti pola Input → Process → Output. Input-nya adalah angka dari pengguna. Process-nya adalah perhitungan pajak, total potongan, dan gaji bersih. Output-nya adalah slip gaji simulasi.

Kenapa alur penting?

Kalau hasil akhir salah, kamu bisa mengecek tahapnya satu per satu: input, proses, lalu output.

Rumus Finansial yang Digunakan

Rumus pertama mengubah persentase menjadi nilai potongan. Karena 5% artinya 5 per 100, Python menghitung persen_pajak / 100 terlebih dahulu, lalu mengalikannya dengan gaji kotor.

Rumus kedua menjumlahkan potongan. Rumus ketiga mengurangi gaji kotor dengan total potongan.

Contoh

Gaji kotor Rp 5.000.000 dan pajak simulasi 5% menghasilkan potongan pajak Rp 250.000.

Variabel sebagai Label Data

Variabel membantu kita memberi nama pada data. Nama seperti gaji_kotor lebih mudah dipahami dibanding x atau a.

Di project finansial, nama variabel yang jelas penting karena kita harus tahu mana input, mana proses, dan mana output.

Hindari typo

gaji_bersih dan gaji_besih dianggap variabel berbeda oleh Python.

Memilih Operator yang Tepat

Operator menentukan jenis perhitungan. * dan / dipakai untuk persentase, + untuk menjumlahkan potongan, dan - untuk menghitung sisa gaji.

Logic error

Kesalahan operator sering tidak memunculkan pesan merah. Program tetap berjalan, tetapi hasilnya salah.

Persentase dalam Python

Dalam bahasa sehari-hari, 5% mudah dibaca sebagai “lima persen”. Tetapi Python perlu nilai yang bisa dihitung: 5 / 100, hasilnya 0.05.

Tanda kurung membuat maksud rumus lebih mudah dibaca.

Kenapa Tanda Kurung Penting?

Python bisa menghitung perkalian dan pembagian sesuai urutan operasi. Namun tanda kurung membuat maksud rumus lebih mudah dibaca oleh manusia.

Prinsip aman

Jika rumus melibatkan persentase, tulis bagian persennya dengan tanda kurung agar jelas.

Input Harus Menjadi Angka

Hasil input() selalu berupa string. Jika ingin menghitung gaji, data perlu diubah menjadi angka dengan int().

Format input

Tulis angka tanpa titik ribuan. Gunakan 5000000, bukan 5.000.000.

Kenapa Perlu Hitung Manual?

Hitung manual memberi patokan sebelum menjalankan kode. Kalau hasil program berbeda jauh, kemungkinan rumus atau operatornya salah.

Contoh default menghasilkan pajak Rp 250.000, total potongan Rp 400.000, dan gaji bersih Rp 4.600.000.

Membaca Logic Error

Logic error terjadi ketika program berjalan, tetapi hasilnya tidak sesuai. Python tidak menganggap rumus ini salah secara sintaks, tetapi secara logika finansial potongan pajak seharusnya mengurangi gaji.

Privasi Finansial

Data gaji termasuk informasi pribadi. Dalam latihan coding, kita tidak perlu memakai data nyata. Tujuan program adalah memahami logika, bukan mengumpulkan informasi asli.

Golden rule

Gunakan data dummy. Jangan memasukkan nama lengkap asli, NIK, nomor rekening, PIN, password, atau nominal gaji nyata.

Testing dengan Data Berbeda

Test case memastikan program bekerja untuk beberapa input, bukan hanya satu data contoh. Jika hasil program tidak sama dengan ekspektasi, cek kembali rumus dan operator.

Batas Logika Program

Edge case adalah kondisi input yang tidak biasa. Program dasar akan tetap menghitung sesuai rumus, sehingga hasilnya bisa negatif.

Kenapa bisa terjadi?

Program belum memiliki validasi untuk menolak input yang tidak masuk akal. Validasi seperti ini biasanya dibuat dengan if.
