Loop punya tiga bagian penting: variabel sementara, range(), dan blok kode yang diulang.

Masalah Kode Berulang

Tanpa loop, menghitung pertumbuhan 10 tahun berarti kamu harus menulis rumus dan print berkali-kali. Selain panjang, kode seperti itu mudah salah.

for loop membantu kita menjalankan pola yang sama untuk jumlah putaran tertentu. Ini cocok untuk simulasi tahun 1, tahun 2, tahun 3, dan seterusnya.

Memahami Bunga Majemuk

Bunga majemuk berarti pertumbuhan berikutnya dihitung dari saldo yang sudah bertambah. Jadi, saldo tahun kedua tidak lagi memakai modal awal saja, tetapi memakai saldo akhir tahun pertama.

Dalam program, konsep ini muncul pada variabel saldo_sekarang. Nilainya terus diperbarui di dalam loop.

Apa Itu Iterasi?

Iterasi adalah satu kali putaran loop. Jika loop berjalan selama 3 tahun, berarti ada 3 iterasi.

Setiap iterasi melakukan urutan yang sama: hitung keuntungan, tambahkan ke saldo, lalu cetak hasil tahun tersebut. Pola yang rapi seperti ini membuat program lebih mudah dicek.

Membaca Struktur for loop

Pada baris for tahun in range(1, 4):, variabel tahun berubah otomatis mengikuti angka dari range().

Tanda titik dua membuka blok loop. Semua kode yang masuk ke dalam loop harus menjorok ke kanan dengan indentasi.

Cara Kerja range()

range(1, 4) tidak berarti 1 sampai 4. Di Python, batas akhir tidak ikut dijalankan, sehingga hasilnya adalah 1, 2, dan 3.

Ini adalah aturan penting karena sering menyebabkan output kurang satu tahun jika kita tidak hati-hati.

Off-by-one Error

Saat user memasukkan durasi 3, kita ingin mencetak tahun 1, 2, dan 3. Karena batas akhir range() tidak ikut, kita menulis durasi_tahun + 1.

Bug seperti ini disebut off-by-one error: program berjalan, tetapi jumlah langkahnya meleset satu.

Indentasi dalam Loop

Python memakai indentasi untuk menentukan baris mana yang menjadi bagian dari loop. Ini bukan hanya soal kerapian tampilan.

Jika baris print() tidak menjorok, Python bisa mengeluarkan IndentationError atau kode tidak berjalan sesuai harapan.

Hitung Manual Sebelum Coding

Hitungan manual membantu kamu punya ekspektasi hasil. Kalau input 100000, 10%, dan 3 tahun, hasilnya harus 110000, 121000, lalu 133100.

Kalau program menghasilkan angka berbeda, kita punya alasan kuat untuk mencari bug pada rumus atau update variabel.

Pola IPO

Program ini tetap mengikuti Input–Process–Output. Input adalah modal, persen, dan durasi. Process adalah loop pertumbuhan. Output adalah deret saldo setiap tahun.

Dengan pola ini, program lebih mudah dibaca dan di-debug.

Peran Variabel

Variabel paling penting di sesi ini adalah saldo_sekarang. Variabel ini berubah setiap tahun dan membawa nilai terbaru ke iterasi berikutnya.

Variabel keuntungan dihitung ulang pada setiap iterasi karena saldo dasarnya juga berubah.

Reading Code

Sebelum menjalankan kode, biasakan memprediksi output. Ini melatih kamu membaca alur program, bukan hanya menekan tombol Run.

Untuk range(1, 4), loop hanya berjalan tiga kali: 1, 2, dan 3.

Brief Project Utama

Project utama bernama Tangga Kekayaan karena outputnya menunjukkan saldo yang naik bertahap dari tahun ke tahun.

Fokus coding-nya adalah membuat loop yang fleksibel. User bisa memilih durasi, dan program menyesuaikan jumlah baris output.

Langkah Input

Bagian input mengambil tiga data. float() dipakai untuk modal dan persen agar bisa menerima angka desimal. int() dipakai untuk durasi karena jumlah tahun berupa angka bulat.

Jangan masukkan titik ribuan di input simulator. Tulis 100000, bukan 100.000.

Konversi Persen

Persen 10% harus diubah menjadi 0.10 agar bisa dipakai dalam perkalian Python. Caranya dengan membagi 100.

Kalau lupa membagi 100, hasil keuntungan akan terlalu besar karena Python membaca 10 sebagai sepuluh kali lipat, bukan 10 persen.

Update Saldo di Dalam Loop

Baris paling penting adalah saldo_sekarang = saldo_sekarang + keuntungan. Baris ini membuat saldo tahun berikutnya memakai nilai yang sudah bertambah.

Jika saldo tidak di-update, output bisa stagnan atau bunga majemuk tidak terjadi.

Program Lengkap

Program lengkap sudah menggabungkan input, konversi persen, loop, output per tahun, dan total keuntungan murni.

Gunakan test case. Jangan hanya mencoba satu angka, karena bug kadang baru terlihat saat durasi atau persen diubah.

Test Case

Test case membantu memastikan program tidak hanya “jalan”, tetapi juga benar. Bandingkan hasil program dengan hitungan manual atau tabel ekspektasi.

Case 1 cocok untuk memeriksa dasar 10% selama 3 tahun. Case 2 membantu melihat apakah rumus tetap berjalan pada nominal dan durasi berbeda.

Trace Table

Trace table memperlihatkan perubahan nilai variabel di setiap iterasi. Ini adalah cara yang sangat berguna untuk mencari logic error pada loop.

Jika saldo awal tahun kedua tidak sama dengan saldo akhir tahun pertama, berarti ada masalah pada update variabel.

Debug Range

Jika output kurang satu tahun, hal pertama yang perlu dicek adalah range(). Ingat, batas akhir tidak ikut dijalankan.

Untuk durasi dari user, pola yang aman adalah range(1, durasi_tahun + 1).

Debug Indentasi

Indentasi adalah aturan struktur di Python. Kode yang ingin diulang harus masuk ke dalam blok loop.

Kalau muncul IndentationError, baca baris yang disebut Python, lalu cek apakah blok setelah titik dua sudah menjorok.

Debug Input Angka

float(input()) menuntut input berupa angka. Kalau user mengetik huruf, Python tidak bisa mengubahnya menjadi angka.

Validasi input yang lebih kuat akan dibahas lagi di sesi try-except, tetapi dari sekarang kamu sudah perlu tahu titik rawannya.

Edge Case

Edge case adalah data yang berada di batas atau terasa “aneh”. Misalnya durasi negatif, pertumbuhan negatif, atau data pribadi asli.

Program dasar belum menolak semua edge case. Tugas kita sekarang adalah mengenali risiko dulu, lalu nanti memperkuat program dengan validasi.

Challenge Total Keuntungan

Total keuntungan murni dihitung setelah loop selesai. Karena itu, barisnya harus sejajar dengan for, bukan menjorok ke dalam.

Kalau diletakkan di dalam loop, total keuntungan akan dicetak berulang setiap tahun, bukan hanya ringkasan akhir.

Operator modulo % mengembalikan sisa bagi. Jika tahun % 3 == 0, berarti tahun tersebut habis dibagi 3.
