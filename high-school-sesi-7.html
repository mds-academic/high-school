    print("LOGIN BERHASIL")

Debug 2: Operator Logika Hilang

Dua kondisi tidak bisa ditaruh berdampingan tanpa penghubung.

# Salah: dua kondisi tidak punya penghubung
if user_input == username_asli pass_input == password_asli:
    print("LOGIN BERHASIL")

# Benar: gunakan and
if user_input == username_asli and pass_input == password_asli:
    print("LOGIN BERHASIL")

Cek cepat

Kalau kalimat logikanya berbunyi “username benar dan password benar”, berarti operatornya and.

Challenge: Batas 3 Percobaan

Di aplikasi nyata, percobaan login biasanya dibatasi untuk mengurangi risiko brute-force.

# Challenge: batas maksimal 3 kali percobaan login
username_asli = "admin_muda"
password_asli = "merdeka123"
percobaan = 0
maks_percobaan = 3

while percobaan < maks_percobaan:
    # User mendapat kesempatan login
    user_input = input("Username: ")
    pass_input = input("Password: ")

    # Jika dua data cocok, login berhasil dan loop dihentikan
    if user_input == username_asli and pass_input == password_asli:
        print("Login berhasil!")
        break
    else:
        # Jika salah, jumlah percobaan bertambah
        percobaan = percobaan + 1
        print(f"Login gagal. Sisa percobaan: {maks_percobaan - percobaan}")

# Jika percobaan habis, akun simulasi terkunci
if percobaan == maks_percobaan:
    print("Akun simulasi terkunci sementara.")

Kode ini memakai while, materi yang akan dibahas lebih lanjut di sesi berikutnya. Kamu boleh mencobanya sebagai challenge.

Analogi Login

Username membantu sistem mengenali siapa yang mencoba masuk. Password membantu membuktikan bahwa orang tersebut memang punya akses.

Kalau username benar tetapi password salah, akses tetap ditolak. Kalau password benar tetapi username salah, akses juga tetap ditolak. Inilah alasan login cocok memakai operator and.

Membaca Kondisi sebagai Boolean

Boolean adalah nilai logika yang hanya punya dua kemungkinan: True atau False. Saat program mengecek username dan password, Python sebenarnya sedang mengecek dua boolean.

Contoh: user_input == username_asli. Jika teksnya sama persis, hasilnya True. Jika beda satu karakter saja, hasilnya False.

Kapan Memakai and dan or?

and dipakai ketika semua syarat harus terpenuhi. Login adalah contoh paling jelas: username benar dan password benar.

or dipakai ketika cukup salah satu syarat benar. Misalnya diskon bisa didapat dari voucher atau poin reward. Kalau salah satu ada, diskon bisa aktif.

Latihan Memilih Operator

Latihan ini membantu kamu memilih operator berdasarkan aturan dunia nyata. Kalau dua hal sama-sama wajib, gunakan and. Kalau cukup salah satu, gunakan or.

Kesalahan memilih operator bisa membuat sistem terlalu ketat atau terlalu longgar.

Assignment vs Comparison

= digunakan untuk memberi nilai. Contoh: password_asli = "merdeka123".

== digunakan untuk membandingkan dua nilai. Contoh: pass_input == password_asli. Dalam kondisi if, yang kamu butuhkan adalah perbandingan, bukan assignment.

Digital Safety untuk Project Login

Login statis adalah cara latihan ketika data akun ditulis langsung di kode. Ini membantu kamu memahami logika and tanpa perlu database.

Namun, jangan pernah memakai data asli. Notebook bisa dibagikan, tersimpan di cloud, atau terlihat saat presentasi.

Mengambil Input Teks

input() selalu menangkap data sebagai teks atau str. Untuk username dan password, ini cocok karena keduanya memang berupa teks.

Dalam project final, kita tidak akan mencetak password user. Pada slide ini password ditampilkan hanya sebagai latihan memahami alur input.

Anatomi if dengan and

Baris if pada login menggabungkan dua hasil perbandingan. Kiri mengecek username. Kanan mengecek password. Operator and memastikan keduanya harus bernilai True.

Kalau salah satu False, Python langsung menjalankan blok else.

Melacak Jalur Program

Trace table membantu kamu melihat cara Python mengambil keputusan. Program tidak “merasa” username hampir benar. Program hanya membaca hasil perbandingan: True atau False.

Pada operator and, hasil akhir hanya True jika semua sisi bernilai True.

Memperbaiki Assignment Error

Dalam kondisi if, kamu ingin membandingkan, bukan menyimpan nilai. Karena itu gunakan ==.

Kesalahan ini biasanya memunculkan SyntaxError karena Python tidak menerima assignment biasa di posisi kondisi seperti itu.

Menghubungkan Dua Kondisi

Python perlu tahu hubungan antara dua kondisi. Apakah keduanya harus benar? Gunakan and. Apakah cukup salah satu? Gunakan or.

Untuk login, penghubung yang tepat adalah and.

Indentasi adalah Aturan, Bukan Dekorasi

Di Python, indentasi menentukan blok kode. Baris di dalam if menjorok. Baris else harus kembali sejajar dengan if.

Kalau struktur indentasi salah, Python bisa memberi IndentationError atau program berjalan tidak sesuai rencana.

Logic Error: Terlalu Mudah Lolos

Ini contoh logic error. Kode tidak crash, tetapi aturan bisnisnya salah. Sistem login menjadi terlalu longgar karena cukup salah satu informasi benar.

Kesalahan seperti ini harus ditemukan lewat test case. Itulah mengapa pengujian kombinasi salah sangat penting.
