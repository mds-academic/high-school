Apa Itu KeyError?

KeyError muncul saat kita memanggil key yang belum ada di dictionary.

rekening_bank = {"Alya": "021-9901", "Budi": "021-9902"}

# Key "Citra" belum ada
print(rekening_bank["Citra"])  # KeyError

Kenapa ini terjadi?

Python tidak menemukan label "Citra", jadi value-nya tidak bisa diambil.

Kenapa Butuh Dictionary?

List cocok untuk data yang urutannya penting. Namun untuk data berpasangan seperti nama → nomor rekening dummy, kita butuh cara yang lebih langsung.

Dengan dictionary, kamu tidak perlu mengingat posisi Alya ada di index berapa. Kamu cukup memanggil key "Alya", lalu Python mengambil value yang terkait.

Pola pikirnya

Daripada mencari berdasarkan nomor urut, cari berdasarkan label.

Key dan Value

Bayangkan daftar kontak. Nama kontak berfungsi sebagai key, sedangkan nomor teleponnya adalah value. Kamu mencari nama, lalu aplikasi menampilkan nomor.

Di project ini, nama nasabah dummy menjadi key. Nomor rekening dummy menjadi value. Pola ini membuat data lebih mudah dicari dan lebih mudah dibaca.

Kalimat penting

Dictionary menyimpan data sebagai pasangan: key: value.

Membaca Sintaks Dictionary

Di Python, tanda {} memberi tahu bahwa data tersebut adalah dictionary. Di dalamnya, tiap pasangan punya key di kiri dan value di kanan.

Kalau ada lebih dari satu pasangan, pisahkan dengan koma. Tanda kutip dipakai karena key dan value pada contoh ini berupa teks.

Hati-hati

Lupa koma, lupa titik dua, atau lupa tanda kutip bisa membuat program error. Untuk awal, ketik pelan-pelan dan cek pasangan tanda kurung.

Latihan Membaca Data

Dalam {"Citra": "021-9903"}, "Citra" adalah key karena dipakai sebagai label pencarian. "021-9903" adalah value karena itulah data yang diambil saat key dipanggil.

Latihan seperti ini kelihatan sederhana, tapi penting. Saat dictionary makin panjang, kamu perlu cepat melihat mana label dan mana isi.

Dictionary sebagai Kartu Data

Satu pasangan key-value bisa dibayangkan seperti satu kartu kontak. Bagian depan berisi nama sebagai label, bagian belakang berisi nomor yang dicari.

Dalam konteks program, Python tidak “menebak” data. Python hanya mengambil value jika key yang diberikan cocok dengan key yang tersimpan.

Dictionary Pertama

Kode ini membuat variabel rekening_bank yang berisi dua pasangan data. Setelah dijalankan, Python menampilkan isi dictionary dan tipe datanya.

Yang perlu diperhatikan

Nomor rekening dummy disimpan sebagai string, bukan angka. Ini wajar karena nomor rekening tidak kita hitung seperti matematika. Nomor itu lebih tepat dianggap identitas teks.

Pola Akses Dictionary

Kalau kamu menulis rekening_bank["Alya"], Python mencari key "Alya" di dalam dictionary. Jika ketemu, Python mengembalikan value yang terkait.

Ini berbeda dengan list. Pada list, kamu mengambil data dengan index seperti data[0]. Pada dictionary, kamu mengambil data dengan key seperti data["Alya"].

Exact Match Itu Penting

Python membandingkan key secara persis. "Alya Nabila" dan "alya nabila" tidak dianggap sama karena huruf kapitalnya berbeda.

Ini penting saat membuat program pencarian. Program dasar kita belum punya fitur validasi atau pencarian fleksibel. Jadi user harus mengetik nama sesuai daftar yang tersedia.

Bug yang sering muncul

KeyError muncul ketika key yang diminta tidak ada di dictionary.

Membaca KeyError

KeyError bukan berarti Python rusak. Itu hanya tanda bahwa key yang kamu minta belum tersedia di dictionary.

Untuk sesi ini, cara paling simpel adalah memastikan input user sama persis dengan pilihan nama yang disediakan. Di sesi lanjutan, kamu bisa menambahkan validasi dengan if agar program memberi pesan yang lebih ramah.

Membaca Dictionary sebagai Tabel

Visual tabel membantu memahami key-value. Key seperti kolom pencarian, sedangkan value adalah data yang dikembalikan.

Karena key dipakai sebagai label, key sebaiknya unik. Kalau key sama dipakai dua kali, Python akan menyimpan value terakhir untuk key tersebut.

Duplicate Key

Dictionary tidak menyimpan dua value untuk key yang sama. Jika kamu menulis key yang sama lagi, value terbaru akan menggantikan value lama.

Dalam aplikasi nyata, duplicate key perlu dicegah atau ditangani dengan aturan yang jelas. Untuk latihan ini, cukup ingat: key sebaiknya unik.

Debugging Dictionary

Bug sesi ini biasanya berasal dari key yang tidak cocok, tanda kutip yang hilang, atau struktur dictionary yang tidak lengkap.

Kalau error muncul, baca pesan error-nya. Cari baris yang ditunjuk Python, lalu cek tanda kutip, titik dua, koma, kurung kurawal, dan key yang dipanggil.

Kenapa Perlu Tanda Kutip?

Tanpa tanda kutip, Python mengira Alya adalah nama variabel. Karena variabel Alya belum dibuat, program bisa memunculkan NameError.

Kalau key-nya berupa teks, panggil dengan tanda kutip: db_rekening["Alya"].
