if kondisi_1: hasil A elif kondisi_2: hasil B else: hasil C

Cocok untuk tiga hasil atau lebih.

Struktur if-elif-else

Perhatikan titik dua dan indentasi 4 spasi. Ini bagian penting di Python.

# Struktur dasar percabangan multi-cabang
if kondisi_pertama:
    # kode untuk kondisi pertama
    print("Hasil pertama")
elif kondisi_kedua:
    # kode untuk kondisi kedua
    print("Hasil kedua")
else:
    # kode jika semua kondisi di atas salah
    print("Hasil terakhir")

Aturan penting

if, elif, dan else harus sejajar. Isi bloknya harus menjorok.

Challenge 2: Cek Rentang Skor

Program dasar belum menolak skor di luar 0–100. Ini preview validasi sederhana.

# Preview validasi sederhana
skor_user = int(input("Masukkan skor simulasi (0-100): "))

if skor_user < 0:
    print("Skor terlalu kecil. Gunakan 0 sampai 100.")
elif skor_user > 100:
    print("Skor terlalu besar. Gunakan 0 sampai 100.")
elif skor_user >= 80:
    print("Zona Aman")
elif skor_user >= 50:
    print("Zona Hati-hati")
else:
    print("Zona Berisiko")

Kenapa ini opsional?

Fokus utama sesi ini adalah if-elif-else. Validasi input yang lebih tahan error akan dibahas lebih dalam di sesi berikutnya.

Challenge Plus: Multi-Faktor

# Preview saja, tidak wajib untuk semua siswa
if skor_user >= 80 and jumlah_tunggakan == 0:

    print("Berisiko Tinggi")

Alur Belajar Sesi Ini

Sesi ini memperluas if-else dari Sesi 5. Sekarang ada if, elif, dan else. Kamu akan belajar rentang nilai, urutan pengecekan, boundary testing, dan debugging. Targetnya bukan sekadar mengetik kode, tapi paham kenapa cabang harus ditulis dalam urutan tertentu.

Persiapan Sebelum Coding

Karena kamu akan sering mencoba input berbeda, workspace perlu siap sejak awal. Pakai notebook dengan nama jelas dan gunakan angka dummy. Jangan memasukkan data finansial asli, nomor rekening, NIK, atau informasi pribadi.

Dua Jalur vs Banyak Jalur

if-else cocok untuk dua hasil. Saat hasilnya lebih dari dua, gunakan elif sebagai pilihan tambahan di tengah. Pada project ini, skor bisa masuk Aman, Hati-hati, atau Berisiko, sehingga struktur if-elif-else lebih cocok.

Membaca Zona Skor

Zona skor adalah aturan kategori yang akan diterjemahkan menjadi kode. Dalam simulasi ini, 80–100 adalah Aman, 50–79 Hati-hati, dan 0–49 Berisiko. Karena Python membaca dari atas ke bawah, kita mulai dari batas tertinggi.

Latihan Klasifikasi Manual

Sebelum menjalankan Python, kamu perlu tahu ekspektasi hasil. Skor 85 masuk Aman, 65 masuk Hati-hati, dan 40 masuk Berisiko. Ini akan menjadi patokan saat mengetes program.

Flowchart Multi-Cabang

Python mengecek kondisi pertama. Jika benar, cabang itu dijalankan dan cabang lain dilewati. Jika salah, Python lanjut ke elif. Jika semua kondisi gagal, else menjadi jalur terakhir.

Urutan Kondisi

Urutan kondisi sangat penting. Jika batas 50 ditaruh sebelum batas 80, skor 85 sudah tertangkap sebagai Hati-hati. Program tidak crash, tetapi hasilnya salah. Ini disebut logic error.

Operator Pembanding

Operator pembanding menghasilkan True atau False. Untuk sesi ini, operator >= paling penting karena nilai batas harus ikut masuk kategori. Skor 80 harus Aman, bukan Hati-hati.

Boundary Testing

Nilai batas seperti 80, 79, 50, dan 49 wajib dites. Angka-angka ini membantu mendeteksi kesalahan operator, terutama saat memakai > padahal seharusnya >=.

Boolean dari Perbandingan

Perbandingan seperti skor_user >= 80 tidak langsung menampilkan kategori. Hasilnya True atau False. Dari hasil itulah Python menentukan cabang program.

Struktur Sintaks

Setiap if, elif, dan else harus diakhiri titik dua. Isi cabang harus menjorok 4 spasi. Di Python, indentasi bukan cuma gaya menulis, tapi bagian dari aturan bahasa.

Reading Code

Latihan ini membiasakan kamu memprediksi output tanpa langsung menjalankan kode. Untuk skor 65, kondisi pertama False, kondisi kedua True, jadi outputnya Zona Hati-hati.

Project Brief

Project mengikuti alur Input, Process, Output. Input adalah skor, process adalah pengecekan if-elif-else, output adalah kategori dan status singkat. Gunakan istilah simulasi agar tidak terdengar seperti keputusan finansial nyata.

Input Skor

input() menerima ketikan user sebagai string. Karena skor harus dibandingkan dengan angka, kita bungkus dengan int(). Jika user mengetik huruf, program akan error. Untuk saat ini cukup pakai input angka.

Cabang Pertama

Cabang pertama mengecek skor minimal 80. Ini harus ditaruh paling atas agar skor tinggi tidak tertangkap oleh kategori tengah.

Cabang Kedua

elif skor_user >= 50 hanya dicek jika skor tidak mencapai 80. Karena itu, cabang ini efektif menangkap skor 50 sampai 79.

Program Utama

Program lengkap sudah memiliki tiga cabang. Jalankan dengan input 85, 65, dan 40. Pastikan hanya satu kategori yang muncul untuk setiap input.

Output Target

Output yang rapi membantu user membaca hasil. Namun tampilan rapi belum cukup. Logika tetap harus diuji dengan beberapa test case.

Test Case

Test case membantu memastikan setiap cabang bekerja. Minimal uji satu angka dari tiap kategori dan beberapa nilai batas.

Trace Table

Trace table menunjukkan jalur yang dilewati program. Ini berguna saat output tidak sesuai ekspektasi, karena kamu bisa melihat kondisi mana yang True atau False.

Debug Titik Dua

Lupa titik dua memicu SyntaxError. Cek semua baris if, elif, dan else. Setiap baris pembuka cabang harus diakhiri titik dua.

Debug Indentasi

elif harus sejajar dengan if. Kalau elif menjorok ke dalam blok if, struktur program menjadi salah dan bisa memicu IndentationError.

Debug Nilai Batas

Bug nilai batas sering terjadi saat memakai >, bukan >=. Program tetap jalan, tetapi skor 80 bisa masuk kategori yang salah.

ValueError

ValueError muncul ketika int() menerima input yang bukan angka. Ini pengantar bahwa aplikasi butuh validasi input, yang akan dipelajari lebih dalam nanti.
